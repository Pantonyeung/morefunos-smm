## Locked design direction
- More Fun 品牌語言
- Customer Web 手機點單流程
- SMT 營運能力
- 白色／暖灰底、橙色主操作色
- iOS 式安全區、底部導航、卡片式資訊層級
- 不採用 SMT 平板側欄購物車
- 購物車只在點單流程以浮動條／獨立頁出現

## Implementation rule
所有後續 SMM 頁面與互動必須以本文件及已核准總覽圖為 UI 基準。任何偏離需重新確認。
